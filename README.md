# 3주차 미션 - 로또 발매기
# 🚀 구현 기능 목록
## 1. 로또 구매 금액 입력 기능
- 로또 1장의 가격은 1000원이다.
- 구입 금액은 1,000원 단위로 입력 받는다.
- 구입 금액에 따라서 로또를 발행 한다.
## 2. 당첨 및 보너스 번호 입력 기능
- 쉼표(,)를 기준으로 6개의 당첨 번호를 입력 받는다.
- 당첨 번호를 입력받고, 보너스 번호를 입력 받는다.
- 당첨 번호와 보너스 번호 모두 중복되지 않아야 한다.
## 3. 발행 로또 번호 및 수량 출력 기능
- 발행한 로또 수량과 번호를 출력한다.
- 로또 번호들은 오름차순으로 정렬되어 있다.
> 출력 예시
```
8개를 구매했습니다.
[8, 21, 23, 41, 42, 43] 
[3, 5, 11, 16, 32, 38] 
[7, 11, 16, 35, 36, 44] 
[1, 8, 11, 31, 41, 42] 
[13, 14, 16, 38, 42, 45] 
[7, 11, 30, 40, 42, 43] 
[2, 13, 22, 32, 38, 45] 
[1, 3, 5, 14, 22, 45]
```
## 4. 당첨 내역 출력 기능
- 당첨은 1등부터 5등까지 있다. 
- 당첨 기준과 금액은 아래와 같다.

|등수|조건|당첨 금액|
|:---:|---|---|
|1등| 6개 번호 일치 | 2,000,000,000원 |
|2등| 5개 번호 + 보너스 번호 일치 | 30,000,000원|
|3등| 5개 번호 일치 | 1,500,000원|
|4등| 4개 번호 일치 | 50,000원|
|5등| 3개 번호 일치 | 5,000원|

>출력 예시
```
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
```
## 5. 수익률 출력 기능
- 로또 구입 금액과 당첨 금액을 비교하여 수익률을 출력한다.
- 수익률은 소수점 둘째 자리에서 반올림 하여 출력한다.
>출력 예시
```
총 수익률은 62.5%입니다.
```
## 6. 예외 처리 기능
> 사용자가 잘못된 값을 입력할 경우 `[ERROR]`로 시작하는 메시지와 함께 Error를 발생시키고 해당 메시지를 출력한 다음 해당 지점부터 다시 입력을 받는다.
### 예외 처리 상황 목록
#### 공통
- 값을 입력하지 않은 경우

#### 구입 금액 입력
- 입력 값 사이에 공백이 있는 경우
- 숫자를 입력하지 않은 경우
- 1000원 단위가 아닌 경우
- 1000원 이하인 경우

#### 당첨 번호 입력
- 숫자로 입력을 시작하지 않는 경우
- 쉼표(,) 구분자 이외의 다른 구분자를 사용하는 경우
- 쉼표와 쉼표 사이에 아무 값도 없는 경우 (ex:, ,) 
- 당첨 번호가 6개가 아닌 경우
- 중복된 당첨 번호가 있는 경우
- 로또 당첨 번호가 1부터 45사이의 숫자가 아닌 경우

#### 보너스 번호 입력
- 입력 값 사이에 공백이 있는 경우
- 로또 당첨 번호가 1부터 45사이의 숫자가 아닌 경우
- 당첨 번호와 보너스 번호가 중복되는 경우

#### 로또 발행
- 로또 번호가 6개가 아닌 경우
- 중복된 로또 번호가 있는 경우
- 로또 번호가 1부터 45사이의 숫자가 아닌 경우
